# Molar Mass Calculator 🧪

A simple, dependency-free Python CLI script designed to calculate the molar mass of chemical formulas.

## Examples:



### Recommended 
No.

### Installation
1. Git clone:
```
git clone https://github.com/MankoMara/molar-mass
```
2. Navigate to directory:
```
cd molar-mass/
```
2. Run the script:
```
python3 main.py
```

### How to use it?
1. Run script.
2. Enter your formula and hit Enter.
3. Good job! 🎉
